## Cerita (ID)

Proyek kelompok PjBL Dasar Pemrograman ini mengembangkan program pemesanan makanan dan minuman untuk Warung Pak Din 2 menggunakan Pascal. Kasir bisa mencatat beberapa menu dalam satu transaksi, menghitung subtotal dan total belanja, memproses pembayaran, lalu mencetak struk. Proyek ini juga menyertakan pseudocode, flowchart, dan media presentasi interaktif berbasis HTML, CSS, dan JavaScript.

## Story (EN)

This Intro to Programming project-based-learning group project builds a food and drink ordering program for Warung Pak Din 2 in Pascal. The cashier can record several menu items in one transaction, compute subtotals and the grand total, take payment, and print a receipt. It also ships pseudocode, a flowchart, and an interactive HTML, CSS, and JavaScript presentation.
