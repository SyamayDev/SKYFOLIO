## Cerita (ID)

I-Teens Management System adalah aplikasi web berbasis React, Vite, dan Supabase untuk mengelola informasi organisasi I-Teens: kegiatan, anggota, dokumentasi, artikel, dan dasbor admin. Autentikasi, basis data PostgreSQL, dan penyimpanan file memakai Supabase, dengan tampilan Tailwind CSS.

## Story (EN)

I-Teens Management System is a React, Vite, and Supabase web app for managing the I-Teens organization: events, members, documentation, articles, and an admin dashboard. Authentication, the PostgreSQL database, and file storage run on Supabase, styled with Tailwind CSS.
