# Gambar referensi

Taruh gambar referensi visual di folder ini. Claude Code akan melihatnya sebelum membuat model terkait.

| Nama file yang disarankan | Isi |
| --- | --- |
| `biplane.png` (atau .jpg) | Contoh bentuk biplane yang kamu suka |
| `pilot-aril.png` | Foto atau gambar untuk gaya avatar pilot |
| `piko.png` | Gambar anak kecil berseragam pilot yang kamu suka gayanya |
| `mood-*.png` | Gambar suasana atau warna yang kamu suka |

Kalau folder ini kosong, Claude Code memakai deskripsi di `docs/04-art-rendering.md`.
